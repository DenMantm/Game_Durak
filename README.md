# Game_Durak

Card Game, most of the code runs on client side. This is working version of russian card game.

**🚀 NEW: Modern React Version Available!**  
Check out the completely rewritten React version in `/durak-react/` with:
- Modern React + TypeScript
- Comprehensive test suite (50+ tests)
- Modular architecture
- Modern build tools
- Mobile-responsive design

## Versions

### Original (Legacy)
Working Version On www.durak.eu.pn

The original implementation uses:
- Express.js 3.4.0 (legacy)
- jQuery for DOM manipulation
- Jade templating
- Monolithic JavaScript architecture

### React Version (Modern - 2024)
Located in `/durak-react/` directory

Features:
- ⚛️ React 19 + TypeScript
- 🧪 50+ comprehensive tests
- 📱 Responsive design
- 🚀 Vite build system
- 🎨 Modern UI/UX
- 🧩 Modular architecture
- 🤖 Improved AI opponent

## Getting Started

### For the Modern React Version (Recommended):
```bash
cd durak-react
npm install
npm run dev
```

### For the Original Version:
```bash
npm install
npm start
```
